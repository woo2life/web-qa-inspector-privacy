Web QA Inspector 개인정보처리방침

시행일: 2026년 9월 28일

Web QA Inspector는 웹페이지의 웹표준, 웹접근성, 성능 및 보안 설정을 점검하는 Chrome 확장 프로그램입니다. 사용자의 개인정보 보호를 중요하게 생각하며, 확장 프로그램이 접근하고 처리하는 정보를 다음과 같이 안내합니다.

1. 처리하는 정보

Web QA Inspector는 사용자가 직접 점검을 실행한 웹페이지에서 다음 정보를 브라우저 내부에서 처리할 수 있습니다.

  • 현재 탭의 제목, URL 및 탭 식별 정보
  • HTML 요소, 속성 및 문서 구조
  • 웹표준·웹접근성·보안 점검 결과
  • LCP, CLS, 로드 시간 등 페이지 성능 정보
  • 점검 일시 및 점검 옵션

이러한 정보는 웹페이지 품질 점검 결과를 제공하기 위한 목적으로만 사용됩니다.

2. 정보의 수집 및 외부 전송

Web QA Inspector는 점검 과정에서 처리한 정보를 개발자 서버나 제3자의 서버로 전송하지 않습니다. 점검은 사용자의 브라우저에서 로컬로 실행됩니다.

광고, 사용자 추적, 행동 분석 또는 맞춤형 광고를 위한 도구를 사용하지 않습니다.

3. 로컬 저장

최근 점검 결과는 사용자가 결과를 다시 확인할 수 있도록 Chrome의 chrome.storage.local 영역에 저장될 수 있습니다.

저장되는 정보에는 점검한 페이지의 제목과 URL, 점검 결과, 성능 정보 및 점검 시간이 포함될 수 있습니다. 이 정보는 사용자의 브라우저 내부에만 저장됩니다.

4. 보고서 다운로드

사용자가 HTML 보고서 또는 인쇄 기능을 이용하면 점검 결과가 사용자의 기기에 파일로 저장될 수 있습니다. 다운로드한 파일은 사용자가 직접 관리하고 삭제해야 합니다.

5. 확장 프로그램 권한

  • tabs: 현재 탭의 제목, URL 및 탭 정보를 확인하기 위해 사용합니다.
  • activeTab: 사용자가 선택한 현재 페이지를 점검하기 위해 사용합니다.
  • scripting: 웹페이지 점검과 문제 요소 찾기 기능을 실행하기 위해 사용합니다.
  • storage: 최근 점검 결과를 브라우저에 저장하기 위해 사용합니다.
  • sidePanel: 점검 화면을 Chrome 사이드 패널에 표시하기 위해 사용합니다.
  • 선택적 사이트 접근 권한: 사용자가 점검을 요청한 웹사이트에 한해 점검 기능을 실행하기 위해 사용합니다.

6. 제한적 사용 및 제3자 제공

Web QA Inspector의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 준수합니다.

  • 처리한 정보는 웹페이지 품질 점검 기능을 제공하거나 개선하는 목적으로만 사용합니다.
  • 사용자 데이터와 점검 정보를 판매하거나 제3자에게 제공하지 않습니다.
  • 사용자 데이터를 맞춤형 광고, 재타겟팅 광고, 관심 기반 광고 또는 신용평가 목적으로 사용하지 않습니다.
  • 사용자가 특정 정보의 공개를 명시적으로 요청한 경우, 법률 준수 또는 보안상 필요한 경우를 제외하고 사람이 사용자 데이터를 읽도록 허용하지 않습니다.

점검 과정에서 처리한 정보는 사용자의 브라우저 내부에서만 사용되며 개발자 서버나 제3자의 서버로 전송되지 않습니다.

7. 정보 삭제

확장 프로그램 내 점검 결과 삭제 기능을 이용하거나 Chrome에서 확장 프로그램을 제거하면 확장 프로그램이 로컬에 저장한 정보를 삭제할 수 있습니다.

별도로 다운로드한 HTML 또는 PDF 보고서는 사용자가 직접 삭제해야 합니다.

8. 개인정보처리방침 변경

확장 프로그램의 기능 또는 정보 처리 방식이 변경되면 이 개인정보처리방침도 변경될 수 있습니다. 변경된 내용은 이 페이지를 통해 공개합니다.
